Only terms that are specific to this project, or that carry a narrower meaning
here than in ordinary use, are listed. General information-technology vocabulary
is deliberately excluded.

| Term | Expansion | Meaning in Project CLOIE |
| --- | --- | --- |
| ACD | Assumption College of Davao | The institution the system is built for. |
| CILO | Course Intended Learning Outcome | A learning outcome associated with one course, describing what students are expected to achieve through it. |
| CLOIE | Comprehensive Learning Outcomes and Instructional Evaluation | The system name. The capstone project is *Project CLOIE*; the software is *System CLOIE*. |
| CQI | Continuous Quality Improvement | An ongoing institutional cycle in which evidence is reviewed and acted on. The system supports evidence collection and review; it does not make academic decisions. |
| GO | Program / Graduate Outcome | A broader outcome associated with an academic program. |
| ILO | Institutional Learning Outcome | An institution-level learning outcome within ACD's academic framework. |
| OBE | Outcome-Based Education | The pedagogical framework that places intended learning outcomes at the centre of curriculum and assessment. |
| PLO | Program Learning Outcome | The system's data-model term for a program-level outcome. |
| Role | — | What a user is *allowed to do*: the set of functions available to them. |
| Scope | — | What a user is *allowed to see*: the courses, programs, periods, or evaluations they are authorized for. Distinct from role, and often narrower. |
| Central evaluation | — | An evaluation deployed at an institutional or program level rather than inside one faculty–course workflow. |
| Course-bound evaluation | — | An evaluation deployed within one course, such as a Post-Term CILO Evaluation. |
| Controlled deployment | — | A configured evaluation that fixes its respondents, context, availability window, and response conditions. |
| Outcome attainment | — | The degree to which an intended outcome is demonstrated, as evidenced by the approved evaluation information available in the system. |
| Stakeholder evaluation | — | An evaluation in which students, graduating students, alumni, or industry partners respond to an approved instrument. |
| Mapping manifestation | — | How a CILO contributes to a broader program outcome, recorded as **Learning**, **Practice**, or **Opportunity**. |
| RTM | Requirements Traceability Matrix | The matrix linking objectives to requirements, to design and implementation, to test evidence. |
| UAT | User Acceptance Testing | Evaluation of the system by representative users before Final Defense. |
